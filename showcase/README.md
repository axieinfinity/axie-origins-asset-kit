# Origins kit showcase

Local catalog of everything in this repo. Pinned stage plays the selected asset; the field below is the full kit.

```bash
cd showcase
npm install
npm run dev
```

Open http://127.0.0.1:5177/

Skill and buff playback uses flipbook previews. Live Origins particles are the Unity prefabs in `Assets/OriginsKit/Prefabs/`. Spine bodies (chimeras, starters, summoners, battle UI) play from the kit files.
