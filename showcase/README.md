# Origins kit showcase

Local catalog of everything in this repo. Pick a kind, inspect the asset, copy the Unity path.

```bash
cd showcase
npm install
npm run dev
```

Open http://127.0.0.1:5177/

Skill and buff playback uses videos recorded from the local Unity player (`VfxLocalPlayer` / `SkillPlayer` at scale 54). Live Origins particles are the Unity prefabs in `Assets/OriginsKit/Prefabs/`. Open the kit in Unity 2021.3 and use Origins → Play Local Player to step through every clip. Spine bodies (chimeras, starters, summoners, battle UI) play from the kit files.
