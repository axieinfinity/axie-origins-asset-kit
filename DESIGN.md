# Design System: Origins Gallery

## Overview

Class System (safer hand). Uncoated paper. Color only means Axie class. The artifact plays in a dark well framed by ink.

## Colors

Paper ground, ink type, hairline rules. The nine class pigments are the only chroma.

## Typography

Atkinson Hyperlegible. One family. Weight and size, not a second face.

## Layout

- Hairline top nav, Axie mark in ink
- Home: specimen well beside the name, then equal collection plates
- Gallery: compact well + caption + class chips + equal-ratio grid
- Phone: menu sheet, stacked well, two-up plates

## Components

Text nav. Hairline chips. Ink outline on the selected tile. Animation chips when a body has more than one clip.

## Motion

Selecting a tile plays it. No page-load choreography.
