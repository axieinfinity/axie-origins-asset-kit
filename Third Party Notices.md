# Third Party Notices

## Spine

Some extracted skeletons (summoners, battle UI banners) are Spine 3.8 data.

Spine Runtimes are licensed by Esoteric Software. You need a valid Spine license to ship Spine runtime code. This kit ships **data** (`.skel` / `.atlas` / `.png`), not the Spine runtime.

## 2D Axie mixer

Axie bodies are **not** in this kit. Use:

- JS/web: `@axieinfinity/mixer`
- Unity: `unity-axie-gtk2d`
- Cocos: `cc-axie-gtk2d`

Mixer animation **names** used by Origins are documented in `Documentation~/MixerAnimations.md`.

## Excluded on purpose

- Epic Toon FX (Unity Asset Store)
- Shop / home / sticker atlases
- HMAC keys, Firebase configs, and other client secrets
