# Contributing

This repo is a **Vibeathon kit** on the Axie Infinity GitHub org (`axieinfinity/axie-origins-asset-kit`), not an open-source project.

- Do not add Epic Toon FX, Asset Store packages, secrets, or home/shop/sticker art.
- If you re-extract from Origins Addressables, rebuild clips with `_extract/rebuild_vfx_clips.py`. Do not `CreateAsset` a bundle clip — Unity drops `m_IsActive` curves.
- Keep `LICENSE.md` as-is.
- Bump `CHANGELOG.md` and `package.json` version together.
